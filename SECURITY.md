# Security policy

Agentic Coder is a skill-only plugin. It does not include a network service, collect telemetry, or
store credentials. Codex accesses repositories and executes commands only according to the
permissions granted by the user in the Codex client.

If you find a security issue in the plugin instructions or packaging, do not include credentials,
private repository content, or exploit details in a public issue. Use GitHub's private security
advisory feature for the published repository when it is available; otherwise contact the
maintainer privately through the repository profile.
